# Round 6 — F6 Comparison trigger

**Map node:** *Does it read as someone else’s highlight reel?*  
**Pages:** `builders.html`, `active-squads.html`, `index.html` hero card, LinkedIn-envy force S7  
**Engine links:** E5 comparison engine, E6 self-efficacy erosion

---

## Objections

1. **Builders can still feel like success porn** if readers only see ships and Venture convert (Maya W8) — not the rough weeks. Collapsed skim = highlight reel.
2. **Active squads “shipping” pills + avatars** mimic GitHub flex culture — upward comparison for grads with empty repos.
3. **Hero engagement graph with green bars** — if you feel like the empty CV person, W1–W4 ACTIVE looks like other people’s discipline.
4. **Four tracks + optional 52-week Venture** can trigger “serious people do Venture; I’m only Sprint” status threat.
5. **Near-peer polish** (Space Grotesk dark UI) signals elite tech club — Olivia/David may feel “not for people like me” or “I must justify investment”; Chloe may feel class filter.
6. **Showcase language** without “first ugly ship” photos invites LinkedIn-style envy (S7).

---

## Delight / come-back-again

1. **Keep rough weeks visible in the fold:** Coral “hard” weeks on builders are the F6 antidote — put one hard week in the home teaser, not only full page.
2. **Anti-reel framing (already strong):** “Not a highlight reel” on builders hero — repeat on active squads.
3. **Show incomplete / paused as normal:** Home already has PAUSED · rough week — make that the featured state once, not only ACTIVE.
4. **Ship #1 ugly on purpose:** Screenshot wireframes, bug notes, triage docs — low-gloss artifacts reduce envy, raise “I could do that.”
5. **Comparison detox line:** Lift Liam W4 — “critique the artifact, not your age” — into a site-wide principle.
6. **Return hook:** Weekly “smallest ship” feature (one object, one person, one scar) — people return for peer oxygen, not envy.

---

## Round verdict

Builders **designed to pass F6** if fully read; **fails F6 on skim**. Active squads **risk fail**. Home is mixed.

**Highest-leverage fix:** Default social proof = paused/rough + first ugly ship, not Venture convert.
